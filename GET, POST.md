# Передача данных в файл handleStudent.php

## GET запрос

Передавать данные к некоторому файлу можно в виде GET запроса. GET запрос можно сформировать в браузере, набрав в
адресной строке путь к сайту
`http://10.3.50.241/handleStudent.php?id=5`
У такого запроса нет тела, потому что браузер не предоставляет возможности в адресной строке добавлять к запросу
какие-либо передаваемые данные. Мы передали в файл набор дополнительной информации в строке адреса: `id=5`.
В файле эти данные можно получить через переменную `$_GET`:

```injectablephp
echo $_GET['id'];
```
